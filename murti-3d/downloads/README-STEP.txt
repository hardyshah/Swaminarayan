Shri Swaminarayan murti - STEP file (free, for personal devotional use)
-----------------------------------------------------------------------
Format: STEP AP214, one closed solid, units = millimetres, scaled to the height in the file name.

Please read: this STEP was converted from the sculpted triangle mesh. It is a "faceted" solid:
its surface is about 100,000 small flat triangles, not smooth CAD (NURBS) surfaces, and it has no
editable features or history. It opens in CAD programs (Fusion, SolidWorks, FreeCAD, Onshape...)
for viewing, measuring, adding a base or a name plate, cutting into parts, or booleans, but it can be
slow and it is coarser than the STL. For 3D printing, use the STL files instead.

The model is a stylised sculpt made from darshan photographs, not a scan of the murti.
Source site: https://hardyshah.github.io/Swaminarayan/murti-3d/
